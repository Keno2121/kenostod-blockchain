---
name: KENO v3 governance rules
description: User-approved token powers, burning model, and temporary custody decision for KENO v3.
---

KENO v3 must remain a fixed one-billion-token, 18-decimal, non-upgradeable token with no future minting, token tax, blacklist, seizure, clawback, or forced transfers. Retain emergency pausing and support true holder-controlled burns that reduce reported supply.

**Why:** The user explicitly approved these protections and chose real burns so supply reporting reflects token destruction.

The protected single wallet may temporarily serve as both owner and initial supply recipient, while the one-time deployer remains separate. This is not the intended permanent governance model.

**Why:** The user selected temporary single-wallet custody instead of creating multisigs before the initial setup.

**How to apply:** Never use the compromised legacy wallet. Preserve two-step ownership transfer, and later move administrative control and treasury custody to separate security and treasury Safe multisigs.
