How it works

Full liquidity-add flow — inside your site, no redirects.

1

Floating button appears

A "💧 Add Liquidity" button is injected into the bottom-right corner of your site automatically after the script loads.

2

Panel shows pool data

Live reserves, current ratio, and the user's token + BNB balances are loaded directly from BSC RPC — no API keys needed.

3

Auto-ratio calculation

User enters one side; the other fills automatically from the pool ratio. Slippage tolerance is 1% by default.

4

Approve → Add

Widget handles ERC-20 approval then calls addLiquidityETH on the PancakeSwap V2 Router. LP tokens land in user's wallet.

The snippet

Paste before your closing </body> tag.

HTML · KENO/BNB (zero config) 
<!-- PancakeSwap LP Funder Widget by Kenostod -->
<script
  src="https://kenostodblockchain.com/pancakeswap-lp-widget.js"
  data-site-id="YOUR_SITE_ID"
></script>
HTML · Custom token pair 
<!-- Any BSC token/BNB pair -->
<script
  src="https://kenostodblockchain.com/pancakeswap-lp-widget.js"
  data-token="0xYOUR_TOKEN_ADDRESS"
  data-token-symbol="MYTOKEN"
  data-pair-name="MYTOKEN/BNB"
  data-site-id="YOUR_SITE_ID"
></script>
JavaScript · Programmatic control 
// Open/close the widget panel programmatically
LPWidget.open();    // open the liquidity panel
LPWidget.close();   // close it
LPWidget.toggle();  // toggle open/closed

// Metadata
console.log(LPWidget.siteId);    // "your-site-id"
console.log(LPWidget.pairName);  // "KENO/BNB"
console.log(LPWidget.version);   // "1.0.0"

Configuration reference

All attributes are optional when using the KENO/BNB default.

Attribute Description Default
data-site-id Your registered site ID (obtain below) demo
data-token BSC address of the ERC-20 token (token0) KENO: 0x48bb…4ab4
data-token-symbol Ticker shown in the UI KENO
data-pair-name Human-readable pair label KENO/BNB
data-api-url Override the Kenostod API base URL https://kenostodblockchain.com
