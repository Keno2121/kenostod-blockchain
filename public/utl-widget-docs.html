How it works

Three steps. One script. Done.

1

User sends a transaction

UTL intercepts the MetaMask call and holds the transaction in a secure 5-minute escrow window.

2

Undo toast appears

A countdown overlay appears on your site. User clicks "Undo" if they made a mistake — wrong address, wrong amount, whatever.

3

Reversal processed

Funds are returned minus a 0.05% reversal fee. If no undo is requested, the transaction finalizes normally.

4

You keep the float yield

Escrowed capital earns 15% APY while it sits in the window. That income flows back to the protocol and KENO holders.
